# أثير القرآن | Athir Al Quran — v5

موقع عربي صغير ومتجاوب للاستماع إلى إذاعات القرآن الكريم: القاهرة والسعودية والكويت والشارقة. استُبعدت قطر من هذه النسخة بسبب مشكلة التشغيل التي أبلغ عنها المستخدم.

## التشغيل والنشر

واجهة ثابتة فقط: لا يحتاج npm أو قاعدة بيانات أو API Key أو باك إند.

1. فك ضغط الملف وارفع المحتويات مباشرة إلى جذر مستودع GitHub. يجب أن يكون index.html في الجذر.
2. GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root) → Save.
3. أو استورد المستودع في Vercel، واختر Other، واترك أمر البناء فارغًا ومجلد الإخراج `.` إذا طُلب.
4. محليًا: شغّل `python3 -m http.server 8000` من مجلد المشروع ثم افتح http://localhost:8000.
5. استبدل الملفات القديمة كلها بالنسخة الجديدة، ثم حدّث الصفحة. روابط CSS وJS تحمل رقم الإصدار لتقليل مشاكل الكاش.

## التشغيل والاستقرار

- لا تشغيل تلقائي عند فتح الصفحة.
- الضغط على المحطة يشغلها، والضغط مجددًا يوقفها.
- عنصر Audio واحد، مع تنظيف HLS والأحداث والمؤقتات عند الإيقاف أو التبديل.
- دعم HLS الأصلي، ومحاولة hls.js كبديل عند فشله حيث يتوفر.
- ثلاث محاولات اتصال كحد أقصى بفواصل 1.5 و3 و6 ثوانٍ. يُصفّر العدد بعد دقيقة من التشغيل المستقر.
- مهلة تحميل ثابتة 25 ثانية لا تعيد أحداث stalled المتكررة تأجيلها.
- مراقبة تقدّم الصوت أثناء ظهور الصفحة، وإعادة الاتصال إذا توقف التقدّم أكثر من 30 ثانية.
- انتظار عودة الإنترنت، ثم استئناف المحطة فقط إن لم يكن المستخدم قد أوقفها.
- رفض تشغيل الصوت بسبب سياسة المتصفح يحتاج نقرة جديدة ولا يسبب محاولات تلقائية.
- اختيار أقل جودة HLS متاحة في مسار hls.js إذا كان بث الراديو يتضمن فيديو مصاحبًا.
- دعم أزرار لوحة المفاتيح وقارئ الشاشة، وأزرار Media Session حيث يدعمها المتصفح.
- بعض أجهزة iOS تعتمد أزرار الجهاز للتحكم في مستوى الصوت.

## الملفات والتعديل

- index.html: الصفحة.
- assets/style.css: التصميم المتجاوب.
- assets/app.js: روابط المحطات والمشغّل. لتحديث الرابط، عدّل url داخل stations.
- assets/vendor/hls.min.js: مكتبة HLS محلية، الإصدار 1.6.13، بترخيص Apache-2.0.
- assets/vendor/hls-LICENSE: ترخيص المكتبة.

## حدود التحقق

فُحصت استجابة مصادر المحطات الأربع، وشمل فحص HLS قوائم التشغيل ومقاطعها الصوتية/المرئية وترويسات CORS. وأُجريت اختبارات محاكاة لمنطق التشغيل والتبديل وإعادة الاتصال. لم يُجرَ اختبار سماع في متصفح فعلي؛ اختبر البث على الجهاز والاستضافة المستهدفين.

الصفحة مستقلة وليست الموقع الرسمي للمحطات؛ يتصل جهاز المستمع بخوادمها مباشرة. لا تُجمع حسابات أو تحليلات زيارات داخل الموقع، لكن مزود البث يرى اتصال المستمع. استمرار الخوادم الخارجية غير مضمون. مصدر القاهرة يعيد التوجيه أحيانًا إلى HTTP، لذلك قد تحظره بعض المتصفحات داخل صفحات HTTPS رغم نجاحه في متصفحات أخرى. إعادة الاتصال لا تعالج حظر HTTPS/CORS. مصادر HLS قد تتضمن صورة أو فيديو مصاحبًا، وقد يظل ذلك مؤثرًا في استهلاك البيانات.

## تحديث المظهر v4
كروت بطبقات وظلال ناعمة، وزخارف أقواس هندسية، وألوان خفيفة مميزة لكل محطة. تتحول المحطة النشطة للأخضر العميق مع مؤشر صوت متحرك وقت التشغيل فقط. تدعم الواجهة تفضيل تقليل الحركة، وتحافظ على الحجم الصغير. منطق البث وإعادة الاتصال كما في v3.

## تحديث v5 — الأعلام والصوت
- أعلام SVG محلية من flag-icons 7.5.0 بترخيص MIT، متوافقة مع Windows والمتصفحات التي لا تعرض أعلام الإيموجي. ملف الترخيص في assets/flags/LICENSE.
- زر كتم وإلغاء كتم مستقل عن إيقاف البث.
- شريط الصوت يظهر عند دعم تغيير مستوى صوت عنصر Audio. على iPhone وiPad يظهر بدلًا منه تنبيه صغير لاستخدام أزرار الجهاز، مع إبقاء زر الكتم. لا نحاول التحكم في مستوى صوت النظام أو تمرير البث عبر Web Audio لتجنب التأثير على استقرار المصادر الخارجية.
- إعادة الضبط بعد مستوى صفر وتحديث حالة الكتم وتسميات الوصول.
- ملفات الأعلام ضمن assets/flags؛ ارفع مجلد assets كاملًا.
